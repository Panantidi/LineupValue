# Local setup

1. Create venv
2. pip install -r requirements.txt
3. uvicorn app:app --reload --host 127.0.0.1 --port 8000


Run: run_local.bat (Windows) or run_local.ps1 (PowerShell)
Site URL after launch: http://127.0.0.1:8000/lineup_ai/FL1010

To access from this laptop on the LAN: http://172.21.13.66:8000/lineup_ai/FL1010
